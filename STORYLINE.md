## SCENE 0 — GLOBAL NETWORK BREACH
*Accent: #00d4ff Cyan | BG base: #000510 deep navy*

The Coders Guild is searching for new recruits to fix the broken cracked server node terminals. You have been selected.

*Accent: #00ff41 Matrix Green | BG base: #000c04 deep forest black*
